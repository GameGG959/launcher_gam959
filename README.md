# MultiTool Site — сайт + сервер аккаунтов, скинов и лобби

Одна папка, один сервер. Он делает всё:

| Что | Где |
|---|---|
| Сайт (скачать, лобби, аккаунт с 3D-скином) | `/` (папка `server/web`) |
| Установщик для скачивания | `/download/…` (папка `server/downloads`) |
| Аккаунты и скины для игры (authlib-injector) | `/yggdrasil` |
| Облако (настройки, миры, скриншоты) | `/api/cloud/…` |
| Лобби мультиплеера (список, коды, пароли) | `/api/lobbies`, `/api/lobby…` |

Сайт и API на одном адресе — переменную `API` в `index.html` трогать не надо.

## 1. Проверить на своём ПК (2 минуты)
1. Нужен Python 3.9+ (python.org, галочка «Add to PATH»).
2. Запусти `run.bat` → открой http://127.0.0.1:8080
3. В лаунчере: **ПРОФИЛИ → Адрес твоего сайта** → `http://127.0.0.1:8080` → СОХРАНИТЬ → РЕГИСТРАЦИЯ.
Так видно только тебе. Чтобы друзья заходили в лобби, сайт должен быть в интернете (п. 2).

## 2. Выложить в интернет
Нужен недорогой VPS (любой, от ~3–5 $/мес, Ubuntu) и домен, направленный A-записью на IP сервера.

**Вариант с Docker (проще всего, HTTPS сам):**
```
apt install -y docker.io docker-compose-v2
# закинь папку MultiTool-Site на сервер, зайди в неё
cp .env.example .env && nano .env        # впиши свой домен в DOMAIN и PUBLIC_URL
docker compose up -d
```
Готово: https://твой-домен. Данные лежат в томе `mt_data` — делай его бэкап.

**Без Docker:** `./run.sh` (gunicorn на порту 8080) и любой прокси с HTTPS (Caddy/nginx) перед ним. Задай переменные `PUBLIC_URL=https://твой-домен` и `BEHIND_PROXY=1`.

Бесплатные хостинги (Render, Railway и т. п.) обычно стирают диск при перезапуске — аккаунты пропадут. Нужен постоянный диск (volume).

## 3. Подключить лаунчер
Впиши адрес сайта в `app/site-api.txt` **до сборки установщика** — тогда у всех он уже стоит. Потом пересобери установщик (`installer/build-hta.bat`) и положи `MultiTool-Setup.hta` в `server/downloads/`. Кнопка «Скачать» на сайте берёт его сама.

## Настройки (переменные окружения / .env)
- `PUBLIC_URL` — внешний адрес сайта (для ссылок на скины);
- `SERVER_NAME` — название в authlib-injector;
- `ALLOW_REGISTER=0` — закрыть регистрацию;
- `LOBBY_TTL` — через сколько секунд без «пульса» лобби исчезает (75).

## Как работают лобби
Хост создаёт лобби в лаунчере → сервер Minecraft и туннель запускаются на его ПК → лаунчер публикует адрес на этом сайте и раз в 15 секунд шлёт «пульс» (кто в игре). Друзья видят лобби в списке или вводят код; лаунчер сам ставит нужную версию и подключает в игру. Пропал «пульс» — лобби исчезает.
- «Аккаунты сайта» — сервер в online-режиме, проверяет игроков через `/yggdrasil`; скины видны всем.
- «По нику» — без проверок, скинов нет.
- Пароль лобби скрывает адрес сервера на сайте; сам Minecraft-сервер пароля не спрашивает.
