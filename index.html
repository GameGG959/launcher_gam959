Добро пожаловать в MultiTool Launcher

Этот проект создавался с нуля как удобная и лёгкая альтернатива громоздким лаунчерам. Цель — быстрый запуск игры и понятный интерфейс.

Ключевые особенности

  • Vanilla, Fabric, Quilt, Forge, NeoForge: любая версия в пару кликов, Java скачивается сама.
  • Моды и сборки: каталог Modrinth, отдельные сборки со своими модами, проверка конфликтов.
  • Аккаунт и скины: вход по логину и паролю, свой скин в игре.
  • Облако: настройки управления, миры и скриншоты синхронизируются между компьютерами.
  • Мультиплеер: свой сервер для друзей на вашем ПК.
  • Умная докачка: лаунчер докачивает только недостающие файлы.

Как это устроено

Лаунчер написан на PowerShell и HTML/CSS/JS: ничего устанавливать дополнительно не нужно, всё работает на встроенных компонентах Windows 10/11.

Частые вопросы (FAQ)

Windows пишет, что файл может быть опасен. Это нормально?Да. Установщик не подписан платным сертификатом, поэтому браузер и SmartScreen перестраховываются. Нажмите «Подробнее» → «Выполнить в любом случае».
Куда скачивается игра?В стандартную папку %APPDATA%\.minecraft. Сборки лежат в .minecraft\instances.
Где хранятся мои данные?Настройки — локально на вашем компьютере. Токен входа в аккаунт хранится зашифрованным средствами Windows.
Лаунчер бесплатный?Да, проект создаётся для удобства игроков.
