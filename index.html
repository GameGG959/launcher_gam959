Смена пароля

MultiTool Launcher

Лёгкий лаунчер Minecraft, сделанный с нуля: быстрый запуск и понятный интерфейс без лишнего мусора.

Что умеет

  • Vanilla, Fabric, Quilt, Forge, NeoForge — любая версия в пару кликов, Java скачивается сама.
  • Моды и сборки — каталог Modrinth, отдельные сборки, проверка конфликтов.
  • Аккаунт и скины — свой скин с этого сайта, виден всем в лобби.
  • Лобби — создай комнату одной кнопкой, друзья заходят по коду. Ничего настраивать не надо.
  • Облако — настройки, миры и скриншоты между компьютерами.

Частые вопросы

Windows пишет, что файл может быть опасен.Установщик не подписан платным сертификатом. Нажми «Подробнее» → «Выполнить в любом случае».
Как работает лобби?Твой ПК запускает сервер, лаунчер сам открывает к нему доступ из интернета и публикует комнату на сайте. Друзья заходят по коду. Пока ты в лобби — компьютер должен быть включён.
Почему в лобби не видно скин?Скины работают в лобби «по аккаунтам сайта». Если хост выбрал «по нику» — у всех стандартные скины.
